## Conflicts to test

Use the user's list first. If they did not give one, test these starter pairs and say that the starter list was used. The starter list is a prompt, not a standard.

| Pair | Why it is on the starter list | Users who hold both | Cleared? |
| --- | --- | --- | --- |
| Vendor master changes and payment release | The same person can create a payee and pay them |  |  |
| Customer master changes and credit notes | The same person can change a customer and write off the balance |  |  |
| Journal posting and the review of that journal | The preparer and the reviewer are the same login |  |  |
| Payroll changes and payroll payment release | The same person can change pay and release the pay |  |  |
| Bank reconciliation and the journals that clear it | The reconciling item can be written by the person who signs the reconciliation |  |  |

A small team may accept a conflict with a review after the event. Record the review. Do not delete the conflict to make the matrix look clean.
