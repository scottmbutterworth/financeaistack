Percentage changes: show last period, this period, and the movement. If the prior period was a loss and this period is a profit, do not print a percentage unless the user has a method they already use, and label it.

## Listing Rule 3.1 watch-out

Read Guidance Note 8: https://www.asx.com.au/content/dam/asx/rules-guidance-notes-waivers/asx-listing-rules/guidance-notes/gn08-continuous-disclosure.pdf

Write a short list of facts in the pack that a reasonable person might expect to be released immediately if they are not already released. Give the list to the company secretary. Do not mark an item as "not material".
