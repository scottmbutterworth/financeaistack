# CFO report structure

Use this order. Drop a section only when you write "not in this pack" and why.

1. One-page summary.
2. Source files and what is missing.
3. Profit and loss, month and year to date, against budget and prior year.
4. Variance commentary.
5. Balance sheet, with a short note on working capital if the file contains debtors, creditors, and inventory.
6. Cash bridge and funding headroom.
7. KPIs, each with its definition and the source column.
8. Risks, judgements, and items the auditor has already raised.
9. Decisions required.
10. Appendix: full exports, so a director can trace a number.
