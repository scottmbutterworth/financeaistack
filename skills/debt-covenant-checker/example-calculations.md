# Example calculation

EXAMPLE DATA. Not a real facility and not a real result. The clause numbers are made up for the example and must never be cited as if they were in a client's agreement.

Example clause 12.1, invented for this file: "Leverage is total net debt divided by EBITDA. It must not exceed 3.00 times. EBITDA adds back interest, tax, depreciation, and amortisation, and does not add back restructuring costs."

Example numbers:

| Input | Example amount | Treatment under the invented clause |
| --- | --- | --- |
| Gross debt | 300 | Included |
| Cash | 50 | Deducted, because this invented clause says net of cash |
| Total net debt | 250 | 300 minus 50 |
| Statutory profit after tax | 40 | Starting point |
| Interest | 20 | Added back |
| Tax | 10 | Added back |
| Depreciation and amortisation | 30 | Added back |
| Restructuring costs | 15 | Not added back. The invented clause does not allow it. |
| EBITDA used | 100 | 40 + 20 + 10 + 30 |
| Leverage | 2.50 times | 250 / 100 |
| Limit | 3.00 times | Invented |
| Headroom | 0.50 times | 3.00 minus 2.50 |

Label on this example only: headroom of 0.50 times. No internal threshold was set in the example, so the example does not say "comfortable".
